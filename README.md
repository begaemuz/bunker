# BUNKER: LAST SIGNAL

Мобильная браузерная игра: Idle Tower Defense / Survivor / RPG / Loot. Вертикальная ориентация, работает офлайн.

## Готово (этапы 1–2 ТЗ)

**Этап 1. Игровое ядро**
- Движок с фиксированным шагом (скорость не зависит от FPS), скорость x1/x2/x3, пауза.
- Бункер в центре поля, энергетические импульсы бьют всех роботов в радиусе одновременно.
- Типы урона, броня, сопротивления, критические импульсы.
- Эффекты: замедление, заморозка, оглушение, поджог, электропоражение, коррозия, снижение брони, цепная молния, доп. импульс, взрыв при уничтожении. Число активных эффектов ограничено слотами.
- Роботы с AI: лёгкий, тяжёлый, дальнобойный, поддержка (лечение и аура брони), камикадзе, элитные (со щитом), мини-босс.
- Волны с ростом HP, урона, брони, скорости, количества и шанса элит. Ремонт бункера между волнами.
- Босс «Колосс-01» на 11-й волне: призыв, щит, энергоудары, ЭМ-подавление, самовосстановление.
- Опыт и уровень бункера, поражение и победа, экран итогов боя.

**Этап 2. Предметы**
- 4 категории оборудования (генераторы, катушки, конденсаторы, реакторы), 13 шаблонов.
- 5 редкостей; характеристики, доп. свойства и слоты деталей генерируются случайно в пределах диапазонов.
- Энергосистема: выработка, потребление, резерв; при дефиците бонусы оборудования снижаются пропорционально.
- Экипировка с проверкой совместимости слотов и сравнением «если установить».
- Инвентарь: разделы, фильтр, сортировка, карточки предметов, продажа с подтверждением, история.
- Сохранение в IndexedDB (с резервной копией), автосохранение, версии сохранений и миграции.

## Структура

- `src/game` — вся игровая логика (не зависит от React): движок, бой, роботы, волны, предметы, экономика, профиль, конфиги баланса.
- `src/render` — отрисовка на Canvas.
- `src/components` — интерфейс на React.
- `src/stores` — состояние (Zustand).
- `src/services` — сохранения и звук.
- `scripts/simulate.ts` — автотесты механик и прогон баланса без браузера.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в один файл dist/index.html
npm run sim      # тесты логики и баланса
```

Каждый пуш в `main` собирается в GitHub Actions; готовый `index.html` лежит в артефакте `game`.
