# BUNKER: LAST SIGNAL

Мобильная браузерная игра: оборонительный комплекс бункера против армии роботов ИИ. Вертикальная ориентация, работает офлайн, прогресс сохраняется на устройстве.

## Что в игре

- **Мой бункер**: 8 физических слотов (генератор, 2 катушки, конденсаторы, преобразователь, охлаждение, сенсоры, защитный контур) на схеме бункера.
- **Энергия, тепло и синергия**: генератор → КПД преобразователя → накопитель → импульсы катушек. Каждый импульс тратит энергию и нагревает комплекс, охлаждение отводит тепло, при перегреве катушки блокируются. Сенсоры опознают цели и дают бонус урона, защитный контур снижает урон.
- **Две независимые катушки** с режимами воздействия: ЭМИ, высоковольтный разряд, радиочастотное подавление, импульс перегрузки, тепловое воздействие, низкочастотная вибрация. У роботов свои сопротивления, броня, щиты, электроника и тяжёлые шасси.
- **Редкость**: обычное → легендарное и уникальное (только с боссов, с особыми свойствами).
- **Улучшение оборудования** с шансом неудачи, уничтожением предмета и защитой стабилизатором. Уровень оборудования ограничен уровнем бункера.
- **Исследования**: 5 направлений, 25 технологий с требованиями по уровню бункера, ресурсам и предыдущим исследованиям.
- **Непрерывный бой**: роботы приходят группами без пауз, угроза постепенно растёт. Награды за слишком слабых роботов снижаются.
- **Боссы по вызову**: после N уничтоженных групп появляется кнопка «Вызвать босса» (или пропуск вызова). Обычные роботы на время боя исчезают.
- **7 локаций** с уникальными боссами, противниками, ресурсами и трофеями; можно возвращаться на открытые.
- Сохранение в IndexedDB с версиями и миграциями (старые сохранения переносятся без потери прогресса).

## Структура

- `src/game/config` — все данные и баланс: оборудование, роботы, боссы, локации, технологии, коэффициенты.
- `src/game/bunker/BunkerStats.ts` — единая функция расчёта характеристик комплекса.
- `src/game/engine` — движок боя (fixed timestep), цикл, визуальные эффекты.
- `src/game/economy/DropSystem.ts` — централизованное выпадение наград.
- `src/game/profile`, `src/game/progression`, `src/game/items` — профиль, локации, технологии, улучшение.
- `src/render` — отрисовка на Canvas, `src/components` — интерфейс React, `src/stores` — Zustand.
- `scripts/simulate.ts` — автотесты механик и прогон баланса автоигроком.

## Запуск

```bash
npm install
npm run dev
npm run build    # один файл dist/index.html
npm run sim      # тесты и баланс (SIM_HOURS=1 для короткого прогона)
```

Каждый пуш в `main` проверяется и собирается в GitHub Actions; сборка публикуется в ветку `build`.
